# Templates

This directory contains starter configuration templates for popular AI coding assistants.

Templates can be copied into a repository after replacing the placeholders marked with `TODO`.

## Structure

- `copilot/` – GitHub Copilot instruction templates (`.github/copilot-instructions.md`)
- `cursor/` – Cursor rule templates (`.cursorrules`)
- `windsurf/` – Windsurf rule templates (`.windsurfrules`)

## Usage

1. Pick the template that matches your AI assistant.
2. Copy the file to the appropriate location in your project (see the path noted at the top of each template).
3. Customise the placeholders marked with `TODO`.
