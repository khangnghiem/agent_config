# Skills

This directory contains reusable skill definitions for AI agents.

Skills are self-contained prompt templates or instruction sets that teach an AI agent how to perform a specific task well. They can be composed and reused across different projects.

## Structure

Each skill is a Markdown file describing:
- **Purpose** – What the skill does
- **Instructions** – Step-by-step guidance for the agent
- **Examples** – Sample inputs and expected outputs

## Usage

Reference a skill file in your agent configuration or paste its contents into a system prompt / instruction file.
