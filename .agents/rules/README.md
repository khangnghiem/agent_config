# Rules

This directory contains rule files that govern AI agent behavior.

Rules define constraints, coding standards, and behavioral guidelines that AI agents should follow when assisting with tasks.

## Structure

- `general/` – General-purpose rules applicable across any project
- `languages/` – Language-specific rules (Python, TypeScript, etc.)
- `frameworks/` – Framework-specific rules (FastAPI, React, etc.)

## Usage

Copy the relevant rule files into your project and reference them in your AI agent configuration (e.g., `.github/copilot-instructions.md`, `.cursorrules`, `.windsurfrules`).
